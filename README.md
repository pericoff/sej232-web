## Rediseño de portada — revisión

Este paquete es una versión estática de la web para **GitHub Pages**. El rediseño solo afecta a la portada (`#inicio`), el bloque introductorio de startups y las cifras destacadas. El resto de contenidos y las 25 publicaciones permanecen tal como estaban en la versión de origen.

### Cómo verlo
1. Descomprime el ZIP completo (manteniendo la carpeta `assets`).
2. Abre `index.html` en Chrome, Edge o Firefox. **No abras el HTML directamente desde el ZIP**.
3. Para publicarlo, sube `index.html`, `publicaciones.json` y toda la carpeta `assets` a la raíz de un repositorio GitHub y activa GitHub Pages (`main`, `/root`).
